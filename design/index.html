CarePlus Pharma · UI template kit

Warm, expressive
pharmacy ERP.

A mock template set built from the app's real design tokens: cream canvas, white cards, coral primary actions, M3 lavender navigation, Plus Jakarta Sans and 20–30px radii. Use these boards as the visual reference for new dashboards, pages, sections and popups — then compare with Direction B, a cooler instrument-like language, at the bottom of this page.

One coral action
Each screen has a single filled coral button. Secondary actions are ghost pills or quiet icon circles.
White page, warm cards
Modules sit on white; cards carry #F1E6DC borders, 26px radii and one soft shadow — never heavy elevation.
Target-aware layout
APK gets 2 × 2 portrait credit-card tiles; web gets one row of four landscape tiles. Same tokens, different density.
Readable by default
Dark ink #241D19 on white, 9px minimum labels in 800 weight, tabular numerals for every amount.

Direction B — Clinical Clarity.

A cooler counter-proposal for the same ERP: apothecary teal, navy ink, 6–12px radii, no gradients, mono numerals, a persistent web sidebar and a table-first density.

Design language 02
06 · CLINICAL CLARITY
Direction B board — all four views
Web shell with persistent sidebar, mobile dashboard, purchase list, table page with receive-stock sheet and the Direction B primitives.
Tight geometry
6px controls, 8–10px cards, 14px app frame. No 26px radii, no floating pills.
Flat elevation
Borders carry structure; shadows are removed except the single app-frame drop.
Mono numerals
Every amount, batch and date uses monospace digits so columns align down the table.
Table-first density
Lists are data tables on web, status-led cards on mobile — same information, different frame.
